Evaluation notes

methodology

Thresholds come from the development set under the twelve tier-1 guardrail constraints and are evaluated on the same served int8 artifacts.

Latency represents model-only single-row inference after warm-up on a laptop. It excludes network, serialization, tokenization, and API overhead.

Boundary probes are intentionally ambiguous. They are useful for inspecting whether a model changes decision behavior close to its selected operating threshold.
